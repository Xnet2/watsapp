חיבור למערכת ימות המשיח

המערכות שלי
הצטרפת לקבוצה הזו דרך קישור הזמנה. פרטי החיבור (טוקן, אנשי קשר, צינתוק) מוסתרים ולא ניתנים לצפייה או לעריכה במכשיר הזה - אפשר לשנות רק את שם התצוגה, או להסיר את הקבוצה מהמכשיר (בכפתור "מחיקת מערכת זו" למטה).

הדרכות

כל הקישורים וההסברים הדרושים כדי למלא כל שדה במסך ההגדרות, מחולקים לפי קטגוריה.

חיבור לימות המשיח חובה

כדי שהאתר יוכל לדבר עם ימות המשיח צריך "טוקן": מספר המערכת שלכם, ואחריו נקודתיים וסיסמה, למשל 0771234567:1234. מספר המערכת הוא מספר הטלפון שדרכו נכנסים לניהול ימות המשיח, והסיסמה היא סיסמת הניהול שלכם (או סיסמה ייעודית שהגדרתם). את זה מזינים בשדה "מספר מערכת וסיסמה".

מספר השלוחה (שדה "מספר שלוחה") הוא השלוחה שממנה יישלפו ההקלטות (הנתיב ivr2:/<שלוחה>/) - ניתן לבדוק אותו בממשק הניהול תחת "ניהול תפריטים".

אנשי קשר אופציונלי

כדי ששמות ותמונות של אנשי קשר יוצגו אוטומטית ליד הקלטות שהתקבלו מהם, מחברים גיליון Google Sheets - דרך שירות חיצוני (SheetDB) או סקריפט Google עצמאי. את הכתובת שמתקבלת מזינים בשדה "כתובת API לאנשי קשר", ובוחרים את הסוג המתאים בשדה "מקור אנשי קשר".

אפשרות א' - SheetDB:

  1. נרשמים ל-SheetDB (יש תוכנית חינמית).
  2. מחברים גיליון Google Sheets חדש/קיים, כשבשורה הראשונה שלו כותרות העמודות: SystemKey, ContactId, Name, Phone, PhotoUrl, UpdatedAt.
  3. SheetDB ייתן כתובת API (Base URL) - מעתיקים ומדביקים בשדה "כתובת API לאנשי קשר".
פתיחת sheetdb.io

אפשרות ב' - סקריפט Google Sheets עצמאי (Apps Script):

  1. פותחים גיליון Google Sheets חדש/קיים, ובשורה הראשונה שלו כותרות העמודות: SystemKey, ContactId, Name, Phone, PhotoUrl, UpdatedAt.
  2. בתוך הגיליון: תפריט Extensions ← Apps Script.
  3. מוחקים את הקוד הקיים ומדביקים במקומו את קוד הסקריפט contacts-appsscript.gs - מפורסם בקישור הבא (הסקריפט ארוך ומתעדכן מדי פעם, לכן לא מודבק כאן וכדאי להעתיק תמיד את הגרסה העדכנית מהפוסט):
  4. Deploy ← New deployment, סוג Web app. תחת Execute as בוחרים "Me", ותחת Who has access בוחרים "Anyone".
  5. מעתיקים את כתובת ה-Web app שמתקבלת (מסתיימת ב-/exec) ומדביקים בשדה "כתובת API לאנשי קשר".
פתיחת הפוסט עם קוד הסקריפט

צינתוק לרשימה אופציונלי

אפשר להגדיר שבכל הקלטה חדשה תישלח אוטומטית שיחת צינתוק לכל המספרים ברשימת צינתוקים שהגדרתם בימות המשיח, תחת "ניהול רשימות צינתוקים במודול צינתוקים חינמיים" בממשק הניהול. את שם/מספר הרשימה מזינים בשדה "שם רשימת צינתוקים" בהגדרות.

פתיחת ממשק הניהול של ימות המשיח

תמלול הודעות אופציונלי, חינמי

תמלול הודעות קוליות לטקסט מתבצע דרך Groq (מודל Whisper), עם מכסה חינמית נדיבה (2,000 בקשות ביום, בלי כרטיס אשראי). את המפתח מזינים בשדה "מפתח Groq API".

  1. נרשמים ל-Groq Console (אימייל או חשבון Google).
  2. בתפריט הצד: API Keys ← Create API Key.
  3. מעתיקים את המפתח (מתחיל ב-gsk_) ומדביקים בשדה "מפתח Groq API".
פתיחת console.groq.com

אנשי קשר

שם ותמונה יוצגו אוטומטית בהקלטות שמזוהות מהמספר שלהם. אנשי הקשר נשמרים בגיליון ה-Google Sheets הפרטי שהוגדר בהגדרות, ונטענים לפי הטוקן - כך שהם משותפים לכל מכשיר שמתחבר עם אותו טוקן, אבל לא נגישים למי שמפעיל את האתר עם גיליון אחר.
